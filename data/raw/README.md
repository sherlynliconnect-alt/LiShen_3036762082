# Raw Data

Place the raw data file `public.csv` in this folder.

## Data Source
The data are publicly available from Princeton University as part of the
Card & Krueger (1994) replication package.

## Expected File
- `public.csv` — restaurant-level survey data for 410 fast-food restaurants
  in New Jersey and eastern Pennsylvania, with pre- and post-minimum-wage
  observations.

## Note
The raw data file is not committed to this repository to avoid uploading
restricted data. Please download it from the original source and place it
in this folder before running the analysis scripts.
